# 🎮 Bots XP - Highrise XP System Bot

بوت نظام XP متقدم للعبة Highrise مع 3 أنظمة مختلفة لكسب النقاط.

## ✨ الميزات

### 🎯 3 أنظمة كسب XP:

1. **⏰ نظام الوقت**
   - كل ساعة كاملة في الروم = 10 XP
   - يبدأ العد من لحظة دخول الشخص الروم

2. **❓ نظام الأسئلة**
   - البوت يسأل سؤال كل 10 دقائق
   - الإجابة الصحيحة = 5 XP
   - أكثر من 50 سؤال متنوع

3. **💬 نظام الرسائل**
   - كل 50 رسالة = 5 XP
   - يتم العد تلقائياً

### 📊 المميزات الإضافية:
- ✅ حفظ البيانات في JSON
- ✅ نظام Levels (كل 100 XP = مستوى واحد)
- ✅ Leaderboard (أفضل 10 لاعبين)
- ✅ أوامر متعددة
- ✅ أوامر خاصة بالمالك

---

## 🚀 البدء السريع

### 1️⃣ المتطلبات:
```bash
pip install -r requirements.txt
```

### 2️⃣ إعداد الإعدادات:
عدّل ملف `config.json`:
```json
{
  "bot_token": "YOUR_BOT_TOKEN_HERE",
  "room_id": "YOUR_ROOM_ID_HERE",
  "owner_username": "T.S.G"
}
```

### 3️⃣ تشغيل البوت:
```bash
python main.py
```

## 📋 الأوامر المتاحة

| الأمر | الوصف |
|------|-------|
| `/xp` | عرض XP الخاص بك ومستواك |
| `/leaderboard` | عرض أفضل 10 لاعبين |
| `/question` | طلب سؤال عشوائي |
| `/help` | عرض جميع الأوامر |
| `/reset @username` | تصفير XP لشخص معين (المالك فقط) |
| `/resetall` | تصفير جميع البيانات (المالك فقط) |

## 🔧 كيفية الحصول على البيانات المطلوبة

### الحصول على Room ID:
1. افتح لعبة Highrise
2. ادخل الروم المطلوب
3. اضغط على معلومات الروم (أعلى يمين)
4. اختر "Share this Room"
5. انسخ الـ ID من الرابط

### الحصول على Bot Token:
1. اذهب لـ Highrise Creator Portal
2. انشئ بوت جديد
3. انسخ الـ Token
